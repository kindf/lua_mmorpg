# lua_mmorpg

一个使用 Lua 编写的 MMORPG 基础玩法示例项目，围绕角色移动、场景更新、AI 指令和技能战斗等内容，演示游戏逻辑的基本组织方式。

> 项目简介：lua实现mmorpg基本移动和战斗

## 项目功能

- **场景与对象管理**：创建游戏场景、角色和怪物，并通过场景心跳推进对象逻辑。
- **角色移动**：通过 AI 命令驱动角色移动，示例中玩家会向目标位置移动。
- **技能与战斗**：支持角色使用技能，并由 Impact 系统处理到期的伤害或治疗结算。
- **固定步长更新**：主循环按 100 毫秒的步长推进仿真时间，依次更新动作时间、场景对象和 Impact。
- **运行状态输出**：定期打印角色位置及角色、怪物的生命值，便于观察演示过程。

## 项目结构

```text
.
├── AI/       # AI 相关逻辑
├── Action/   # 动作与时间更新
├── Config/   # 配置
├── Define/   # 常量与基础定义
├── Handler/  # 处理器逻辑
├── Network/  # 网络相关模块
├── Obj/      # 游戏对象与角色
├── Scene/    # 场景逻辑
├── Skill/    # 技能与效果结算
├── Tool/     # 工具模块
└── main.lua  # 程序入口与演示主循环
```

## 运行方式

确保环境中已安装 Lua，并在项目根目录执行：

```bash
lua main.lua
```

程序会创建一个场景、玩家和怪物，先演示玩家移动，再尝试对怪物使用技能，并在控制台输出仿真状态。

## 说明

这是一个用于学习和演示 MMORPG 基础移动与战斗逻辑的 Lua 项目。当前入口脚本展示的是本地游戏逻辑仿真流程。
